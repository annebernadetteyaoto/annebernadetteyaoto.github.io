Features:
  Live Czech and Philippine time
  Live weather from Liberec X-Františkov
  Live calendar in Czech time zone

Hosting:
  Can either be hosted locally on mobile or via VS Code on PC. 
  Local hosting:
    Install HTTPS Server or something similar, but it would only last a few hours at most without paying.
  Hosting on PC via VS Code:
    Install the Live Server extension.
    Right click on index.html and select Open with Live Server.
    Find your PC's IP address, and open this link on your phone browser: https://[your PC's IP address]:5500.
